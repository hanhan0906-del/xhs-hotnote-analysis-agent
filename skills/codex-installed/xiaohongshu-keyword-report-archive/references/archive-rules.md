# Archive Rules

## Create vs Merge

Create a new entry when:

- The formula structure is materially different.
- The search intent is different even if words overlap.
- The evidence points to a distinct user need.

Merge into an existing entry when:

- The core formula is the same.
- New examples only expand evidence or limitations.
- The existing entry already covers the same search intent.

When uncertain, create a separate entry and add a `参见` link instead of forcing a merge.

## Evidence Levels

Use these labels:

- `强证据`: multiple high-performing notes or one very strong low-follower breakout plus supporting notes.
- `中证据`: one strong note plus several directionally similar notes.
- `弱证据`: one note only, or sample too noisy; keep as observation rather than stable formula.

## Filename Rules

- Use the formula name as the filename.
- Remove Windows-invalid characters: `< > : " / \ | ? *`.
- Keep filenames readable and under 80 Chinese characters when possible.
- If a duplicate filename exists but should not merge, append a short qualifier such as `-防坑型` or `-社会化型`.

## Do Not Archive

Do not archive:

- A one-off viral title with no generalizable structure.
- A generic title such as "职场新人指南" unless the report explains why its exact packaging worked.
- Tags as fixed reusable formulas.
- Full note bodies.
- Images into title-library folders.
